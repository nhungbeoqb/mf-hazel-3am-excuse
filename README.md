A make.fun entry for [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878): one line under 200 characters, in the voice of a hardware wallet that refuses to sign a transaction at 3 AM.

## The line

> At 3 AM I don't sign transactions — I file restraining orders against you, from you, until the sun clocks in as my witness.

## How it runs

`main.py` writes the line to `/output/entry.txt`. Run it twice and the output is byte-identical.
